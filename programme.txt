Mois 1 — Reprendre la programmation avec Python
🎯 Objectif du mois

À la fin des 4 semaines, tu dois être capable de :

écrire de petits programmes Python seul ;
comprendre les variables, conditions, boucles et fonctions ;
manipuler des listes et dictionnaires ;
lire et écrire des fichiers ;
comprendre les erreurs de base ;
utiliser un terminal et Git de façon élémentaire ;
avoir réalisé un petit projet personnel.

Et surtout : ne pas simplement regarder des vidéos. Tu dois coder.

🗓️ Semaine 1 — Découverte de Python

Objectif : comprendre la logique de base.

Lundi — Installation et découverte

1 h 30

Installer Python.
Installer VS Code.
Créer un dossier apprentissage-python.
Découvrir le terminal.
Faire ton premier programme :
print("Bonjour, je commence mon apprentissage de Python !")

Ensuite, teste plusieurs print().

Exercice :

Faire afficher ton prénom, ton âge et ton objectif professionnel.

Mardi — Variables

Apprendre :

chaînes de caractères ;
nombres entiers ;
nombres décimaux ;
booléens ;
affectation de variables.

Exemple :

age = 48
metier = "Concepteur Designer UI"
objectif = "Médiateur numérique"

Exercice :

Créer un petit programme qui affiche une présentation de toi.

Mercredi — Calculs et conversions

Apprendre :

+
-
*
/
%

Puis les conversions :

int()
float()
str()

Exercice :

Créer un programme qui demande ton âge et calcule approximativement ton année de naissance.

Jeudi — Conditions

Apprendre :

if
elif
else

Exemple :

age = 48

if age >= 18:
    print("Vous êtes majeur.")
else:
    print("Vous êtes mineur.")

Exercice :

Créer un programme qui demande l'âge d'une personne et affiche une catégorie :

moins de 18 ans ;
18–29 ;
30–49 ;
50 ans et plus.
Vendredi — Petit projet 1

Tu combines tout ce que tu as appris.

Projet : "Mon profil numérique"

Le programme demande :

prénom ;
âge ;
métier ;
objectif.

Puis il affiche une présentation.

🎯 Vendredi soir : tu dois avoir ton premier petit programme fonctionnel.

Samedi + dimanche : repos.

🗓️ Semaine 2 — Listes, boucles et dictionnaires

Cette semaine est importante.

Tu vas commencer à comprendre comment un programme manipule des données.

Lundi — Les listes

Apprendre :

noms = ["Paul", "Marie", "Sophie"]

Puis :

ajouter ;
supprimer ;
modifier ;
récupérer un élément.

Exercice :

Créer une liste de 10 compétences que tu veux apprendre.

Mardi — Les boucles

Apprendre :

for

Puis :

while

Exemple :

competences = ["Python", "IA", "Git"]

for competence in competences:
    print(competence)

Exercice :

Afficher automatiquement les 10 compétences de ta liste.

Mercredi — Les dictionnaires

Apprendre :

personne = {
    "nom": "Dupont",
    "age": 48,
    "metier": "Designer UI"
}

Comprendre les clés et les valeurs.

Exercice :

Créer un dictionnaire représentant ton profil professionnel.

Jeudi — Mélanger les concepts

Créer une liste contenant plusieurs personnes.

Puis afficher leurs informations avec une boucle.

Exemple :

personnes = [
    {"nom": "Paul", "age": 25},
    {"nom": "Marie", "age": 42},
    {"nom": "Jean", "age": 51}
]
Vendredi — Petit projet 2

Créer un mini carnet de contacts.

Ton programme doit pouvoir :

afficher les contacts ;
ajouter un contact ;
rechercher un contact.

Tu n'as pas besoin d'une interface graphique.

Le programme peut fonctionner directement dans le terminal.

🎯 Tu commences à construire quelque chose qui ressemble à une vraie application.

🗓️ Semaine 3 — Fonctions + fichiers + erreurs

Là, on commence à passer un cap.

Lundi — Les fonctions

Apprendre :

def

Exemple :

def dire_bonjour(nom):
    print("Bonjour", nom)

Comprendre :

paramètres ;
valeurs de retour ;
return.

Exercice :

Créer plusieurs petites fonctions pour ton carnet de contacts.

Mardi — Organiser ton programme

Reprendre le projet du carnet de contacts.

Au lieu d'avoir 100 lignes mélangées, créer :

ajouter_contact()
supprimer_contact()
rechercher_contact()
afficher_contacts()

🎯 Objectif : commencer à écrire du code organisé.

Mercredi — Lire et écrire des fichiers

Apprendre à utiliser des fichiers .txt.

Puis découvrir les fichiers JSON.

C'est particulièrement important pour la suite parce que les API et les applications web utilisent énormément ce type de données.

Jeudi — Gérer les erreurs

Découvrir :

try
except

Exemple :

try:
    age = int(input("Quel âge avez-vous ? "))
except:
    print("Veuillez entrer un nombre.")

Exercice :

Faire en sorte que ton programme ne plante pas immédiatement lorsqu'un utilisateur entre n'importe quoi.

Vendredi — Projet 3

Améliorer ton carnet de contacts.

Cette fois :

les contacts sont sauvegardés dans un fichier ;
ils sont récupérés quand tu relances le programme ;
tu peux ajouter/rechercher/supprimer ;
les erreurs basiques sont gérées.

🎯 Ça devient ton premier véritable petit projet.

Mercredi — Ton projet

On va commencer quelque chose qui correspond à ton futur profil.

Projet : « Assistant numérique débutant »

Version 1, très simple.

Une personne choisit une question :

1 - Créer une adresse email
2 - Utiliser un moteur de recherche
3 - Créer un mot de passe
4 - Reconnaître une arnaque
5 - Utiliser ChatGPT

Le programme affiche ensuite une explication simple.

Par exemple :

Créer une adresse email

Choisissez un fournisseur de messagerie.
Cliquez sur créer un compte.
Choisissez votre adresse.
Créez un mot de passe suffisamment sécurisé.
Notez vos informations dans un endroit sécurisé.

Ce projet est volontairement très simple.

Jeudi — Améliorer l'assistant

Ajoute :

des fonctions ;
des catégories ;
une recherche ;
une gestion des erreurs.

Par exemple :

« Je cherche comment créer un mot de passe. »

Ton programme doit pouvoir retrouver l'information correspondante.

Est-ce que je sais manipuler une liste ?

Est-ce que je sais lire/écrire un fichier ?

Est-ce que je peux créer un petit programme sans copier exactement un tutoriel ?

Et surtout :

Cette dernière question est probablement la plus importante.

⏰ Ta routine quotidienne

Pour tes 1 h 30, je te conseille :

15 min → revoir ce que tu as fait la veille.

45 min → apprendre une nouvelle notion.

30 min → exercices.

15 min → essayer quelque chose tout seul.

15 min → noter ce que tu as compris / ce qui te bloque.

Ne fais surtout pas :

1 h 30 de vidéos.

Fais plutôt :

20 % théorie / 80 % pratique.

🚨 Et une règle importante

Pendant ce premier mois, ne pars pas encore dans les frameworks IA, les agents, LangChain, les modèles, le machine learning, etc.

Tu vas probablement avoir envie de toucher à tout.

Résiste.

Ton objectif est d'abord de construire des fondations suffisamment solides en programmation.

Le mois 2 pourra ensuite introduire Python + API + IA, et là tu commenceras à voir le lien avec ton objectif.
